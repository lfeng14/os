## 内容概览

### 核心模块

| 模块 | 内容 |
|------|------|
| **进程管理** | fork/execve 系统调用、Shell、管道、进程组、信号处理 |
| **内存管理** | 虚拟地址空间、动态链接加载、COW、ELF 格式 |
| **文件系统** | 磁盘抽象、FAT/EXT2、缓冲区缓存、日志技术 |
| **调度算法** | 优先级调度、实时调度、公平调度 |
| **设备IO** | 中断机制、DMA、设备驱动模型 |

### 特色

- 大量代码示例和调试技巧
- GDB、strace 等工具的实战使用
- xv6 教学操作系统详细分析
- 基于 [jyywiki.cn](https://jyywiki.cn/OS/2024/) 课程

## 学习路径

1. 从 **01-基础概念** 开始，了解可执行文件格式和调试工具
2. 学习 **02-进程管理**，理解进程创建与通信
3. 深入 **03-内存管理**，掌握虚拟内存机制
4. 研究 **04-文件系统**，学习持久化存储
5. 阅读 **06-系统实现** 中的 xv6 代码，理论结合实践
